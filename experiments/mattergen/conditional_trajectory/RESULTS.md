# 带隙条件生成轨迹：ALIGNN 目标误差与阶段变化

本实验完成于 2026-10-30。目标带隙 2.5 eV，使用缓存的官方
`dft_band_gap` checkpoint，比较 CFG=2 与同一权重的无条件分支 CFG=0。
每组 12 条轨迹，分为 3 个原生 batch，每个 batch 4 条；两组使用相同
原子数、配对随机种子和逐数组核对一致的初始先验。生成遵循原生 1000 轮
predictor-corrector，不加 CF、MatterSim 弛豫、DFT 或 SUN。

这里采用的是同时生成元素、晶胞和坐标的原生条件模型，区别于此前固定组分的
纯 CSP 实验。每 5 轮记录 predictor 输入，另记录 prior、999 轮输入，以及
实际返回的终态 mean1000；共 24 条轨迹、4872 个状态。

MAE 指 `mean(abs(ALIGNN_gap - 2.5 eV))`，衡量目标符合程度，不是与 DFT
标签比较的预测精度。含 MASK101 的状态不作性质预测，也不回填最终元素。
356 个状态可评估，均完成 ALIGNN 和 MatterSim 单点计算；其余 4516 个状态
因原子类型未确定而排除。含噪几何上的 ALIGNN 预测尚未校准。

## 主要描述性结果

| 首次元素全部确定的步数中位数 | 970 | 957.5 |
| 首次元素全部确定的步数范围 | 910–1000 | 620–995 |
| 各自首次可评估时的目标 MAE / eV | 1.801894 | 2.211269 |
| 最终目标 MAE / eV | 1.918878 | 2.159906 |
| 同一结构首次可评估→最终的误差平均变化 / eV | +0.116984 | −0.051363 |
| 上述区间误差下降的结构数 | 2/12 | 7/12 |
| 上述区间 MatterSim RMS 力下降的结构数 | 11/12 | 12/12 |
| 首次可评估时 RMS 力中位数 / (eV/Å) | 0.798630 | 0.667988 |
| 最终 RMS 力中位数 / (eV/Å) | 0.167315 | 0.105454 |
| 相邻可评估观测中目标误差上升次数 | 48/97 | 112/235 |

首次可评估的时间因结构而异，不能把这一行解释为同一去噪步的横截面。
所有结构从首次可评估到终态均保持相同的原子种类；这段误差变化不由换元素引起。
条件组最终平均误差较无条件组低 0.241028 eV，即 11.16%；三个原生 batch
中有两个改善，一个变差，样本不足以据此宣称稳健提升。

## 各阶段的可观察变化与解释边界

以下区间用于描述曲线，不代表采样器在这些时刻切换了算法。
原子类型、坐标和晶胞在整个采样过程中共同演化，条件嵌入始终参与条件组评分。

- **0–500 轮：高噪声状态与逐步确定元素。** 条件组 MASK 原子比例从 100%
  降至约 54.3%；最近原子间距中位数仍约 0.68 Å。没有完整组成可供 ALIGNN
  预测带隙。不能从 MAE 空白推断条件在早期不起作用。
- **约 500–900 轮：几何逐渐整理，元素仍未完全确定。** 条件组最近原子间距
  中位数由约 0.68 Å 增至 1.86 Å；900 轮时平均仍有 18.8% 的原子为 MASK，
  12 条轨迹中尚无一条可直接评估带隙。这支持几何从拥挤噪声向更合理排列演化，
  但未解析元素时不能据此判断其真实能量或带隙。
- **约 900–1000 轮：完整组成逐步出现，低噪声几何继续去噪。** 力整体下降，
  目标误差则非单调。条件组同路径的平均误差反而增加约 0.117 eV。
  后段更符合几何去噪和结构整理，而非沿 ALIGNN 目标误差持续下降。

条件引导的总体收益可能已通过更早的组分和结构分布选择体现；当前实验不能
把组分作用与几何作用因果分离，也不能证明真实 DFT 带隙随去噪恶化。
尚有非零终态力，不能将原生输出直接等同于经过严格结构弛豫的稳定结构。

可评估集合随时间变化，会造成均值跳变。例如，条件组 999 轮有 11 个可评估
结构，MAE 为 2.023725 eV；终态加入第 12 个后为 1.918878 eV。若保留原来的
同 11 个结构，终态 MAE 为 2.021030 eV，实际平均改善仅 0.002695 eV。
因此最终一跳的大部分来自新增样本，而非同一批结构的带隙快速改善。
从 500、750、900 轮起始的全时段双组固定共同队列均为空，JSON 保留这一事实；
图中使用相同父结构的首次可评估/终态散点补充描述，并明确各自起点不同。
