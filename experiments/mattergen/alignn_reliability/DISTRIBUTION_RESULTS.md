# 当前 ALIGNN 训练集的带隙众数

2026-10-31。当前冻结模型为 `mp_gappbe_alignnn.zip`。按照该检查点保存的
`id_train` 回查缓存 MEGNet 数据的 `gap pbe`，统计恰好 60000 个训练结构的
DFT/PBE 带隙标签，不包括 5000 验证结构和 4239 测试结构。

**众数为 0 eV：21090 / 60000 = 35.15%。**

| 统计口径 | 结果 | 数量 |
|---|---|---:|
| 全训练集精确众数 | 0 eV | 21090 |
| 正带隙结构 | 带隙 >0 eV | 38910 |
| 正带隙子集精确众数 | 约 0.0023 eV | 20 |
| 正带隙子集 0.1 eV 分箱峰值 | (0, 0.1) eV | 3473 |
| 全训练集带隙中位数 | 0.6650 eV | — |
| 正带隙子集带隙中位数 | 1.88285 eV | — |

精确正值众数受标签精度影响，仅重复 20 次，不能作为有代表性的半导体目标。
分箱峰值依赖箱宽和原点；上述采用从 0 开始的 0.1 eV 左闭右开区间，正值筛选
排除了精确零。分箱峰值不等于精确众数。

| 候选目标 / eV | 目标 ±0.2 eV 内训练结构数 | 占全部训练集 |
|---|---:|---:|
| 0.0 | 25724 | 42.87% |
| 0.5 | 3644 | 6.07% |
| 1.0 | 3492 | 5.82% |
| 1.5 | 3503 | 5.84% |
| 2.0 | 3471 | 5.79% |
| 2.5 | 3194 | 5.32% |
| 3.0 | 2754 | 4.59% |

0 eV 可作为 GRPO 流程验证的候选目标，但高占比不保证奖励有足够区分度，
也不保证 ALIGNN 对生成结构预测准确。现有推理将负带隙截为 0，目标为 0 时
可能出现大量最高奖励并列；需要检查组内奖励方差和独立性质验证。若研究目标
是有限带隙半导体，1–2 eV 是可考虑的初始目标范围，最终应按目标附近的预测
可靠性和基线生成分布选择。2.5 eV 附近的训练样本也不算极端稀少，不能仅由
众数认定此前目标不合理。此轮没有运行 GRPO 或 MatterGen 训练。

## 来源与验证

- 检查点 ZIP SHA256：`8e9309fcb435a88481ccbc945d16cb1343f9ac24d8198607f753ce59b687242e`。
- 数据集 ZIP SHA256：`0f5deb0beebd22131b98ab2be551b12edfed9838841e627210f564c4e83f425f`，共 69239 条；与上一轮可靠性分类实验一致。
- CPU Slurm 517 成功，统计阶段 41.60 秒。最初 516 因假定归档训练预测 CSV 含 ID 而失败，失败证据保留。
- 实际归档训练 CSV 仅有 `target,prediction` 两列、9984 行，不能与 60000 个 ID 做逐点比对；未根据行序猜测标签。统计始终使用训练 ID 与原始数据集的键连接。
- 16 项本地测试通过。下载的 60000 行 ID/标签表 SHA 与远程结果一致；本地独立 Counter 核对众数、零/正值数量及 21 个目标窗口计数全部通过。
- 本地证据目录：`results/mattergen/evidence/alignn-training-gap-mode-20261031/`，含 `distribution.json`、`training-gaps.tsv.gz`、`audit.json`，均作为生成物忽略。
