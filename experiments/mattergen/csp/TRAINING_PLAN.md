# 固定组分、带隙条件 CSP 的训练方案

2026-10-30；这是待实施方案，尚未训练、运行 GPU smoke 或统计实际标签量。
首选复用已校验的 GSS MatterGen CSP 基座，添加带隙条件适配器。目标为
`p(坐标, 晶胞 | 每个晶胞的精确元素计数, 目标 DFT 带隙)`。
现有带隙联合生成模型不作为 CSP 权重直接替换，也不从随机权重重训整个模型。

## 先确认数据是否支持研究问题

数据优先使用同一 DFT 标注体系的 MP-20 / Alex-MP-20 带隙有效子集。不得把缺失
带隙当成零：零带隙是有效金属标签。首版保留最多 20 原子的范围，去除重复结构，
保留同组分的不同多晶型。PBE/HSE/实验带隙不能直接混成同一条件标签。
实际可用样本数必须从数据审计取得，不据总结构数推断有标签数。

先报告：有效带隙数量、零带隙比例和带隙分布、唯一约化组分数、每组多晶型数、
同组分内带隙极差/方差，以及相同原子计数或可比晶胞大小下这些统计的变化。
不同原胞大小可能限制固定原子计数时能表示的多晶型，不能只按化学式计数。

**最关键的数据风险：带隙条件可能只是组分的代理。** 若同一组分只有一个结构
和一个带隙，单凭性质微调无法充分证明模型能在固定组分下调节几何来改变带隙。
先寻找存在结构/带隙变化的多晶型组，作为条件作用的诊断集合；其余有效数据仍
可以用于总体微调，但不能替代这个诊断。若组内带隙变化不足，先补数据而不是
只增加训练步数。对高频零带隙可比较自然采样与分箱重采样，完整记录采样分布。

微调集按约化组分分组划分 train/validation/test，例如 80/10/10；同一多晶型、
超胞重复或等价结构不能跨集合。性质标准化仅用 train 拟合。
GSS 基座已在 Alex-MP-20 上预训练，重划分微调数据不能消除基座的历史结构泄漏。
因此首轮结果只能称微调隔离/条件可控性实验。正式声称全流程未见组分或结构，
需要额外的预训练集之外测试数据，或另行训练具有可审计划分的基座。

## 模型与监督

复用原 CSP 的元素嵌入、几何去噪器和加噪日程，添加
`property_embeddings_adapt.dft_band_gap` 与逐层 GemNet 条件控制层。
带隙经训练集均值/标准差标准化后编码，与噪声时间一起输入模型。
先设 `adapter.full_finetuning=false`：冻结原有参数，只训练新增参数。
如果适配器有效但能力明显受限，再比较解冻后层或小学习率全量微调。

对平衡结构 `x0=(坐标,晶胞)`、固定组分 `c` 和其 DFT 标签 `y0`：

1. 采样原生噪声时间，只给坐标和晶胞加噪，得到 `xt`；元素不加噪、不替换。
2. 模型读入 `(xt,t,c,y0)`，学习恢复对应的几何去噪方向。
3. 监督沿用原生坐标 wrapped-normal loss 和晶胞去噪 loss，首版保留 CSP 的
   `L=0.1*L_pos+1.0*L_cell`；关闭元素损失，禁止离散元素 corruption。
4. 以 20% 概率移除性质条件，保留 classifier-free guidance 的条件/无条件接口。

这里的 `y0` 始终是干净参考结构的 DFT 带隙，**不是含噪结构的即时带隙**。
首版不通过 ALIGNN 在 `xt` 上回传梯度，也不添加
`abs(ALIGNN(xt)-y0)` 作为训练损失。训练由已知加噪过程监督，因此不要求
ALIGNN 在高噪声几何上可信。

## 初始试验参数与推进顺序

以下均为提议值，不是已验证的最优超参数或显存保证。

| 项目 | 首轮提议 |
|---|---|
| 基座 | 已校验 GSS CSP，原始权重保持不变 |
| 训练参数 | 新增性质嵌入和控制层，先冻结原参数 |
| 优化器 | Adam，适配器学习率先试 1e-5，5e-6 作保守对照 |
| 学习率日程 | 约 200 个优化器步 warmup，再 cosine 衰减至约 1e-6 |
| 条件 dropout | 0.2 |
| 精度 | FP32 先跑通；混合精度须额外验证损失与梯度 |
| 单卡 microbatch | 从 2–4 个结构起测，不预先承诺更大 batch |
| 累积梯度 | 使有效 batch 约 16–32，记录实际优化器步数 |
| 梯度裁剪 | 范数 1.0 作为初始提议 |
| 第一期训练 | 约 2000–5000 个优化器步的可行性 pilot，按验证结果决定延长 |

先用少量多晶型样本检查可学习性，再运行 200 个优化器步的单卡基准：报告每步
时间、峰值显存和有效结构吞吐，之后才估计完整训练用时。冻结权重不等于可以
对穿过控制层的前向全部使用 `no_grad`；仍须保留必要的反传路径。
全部远程训练、预处理和评估经 Slurm；首轮不提交并发大任务。

## 必须通过的实现检查

- 上游微调函数会复制基座的整个 diffusion 配置，应核对最终解析配置确实保留
  CSP corruption/loss；不要仅凭保留的 atom-type 输出头判断是否训练元素。
- 校验基座文件哈希；复制参数逐项对上名字、形状和值，明确新增参数清单。
  可信旧格式 checkpoint 加载沿用项目已有的哈希白名单机制。
- GemNet 控制混合层采用零初始化。训练前条件分支/无条件分支应与基座几何
  输出一致；更新后条件分支应产生差异，无条件分支在冻结方案下仍应保持基座。
  零初始化可能使部分上游新增层首步梯度为零，不能要求所有新增参数首步都非零；
  应检查控制投影先得到梯度，并在若干步后确认条件嵌入参与学习。
- 数据加载、加噪、每次采样输入及终态逐一验证原子种类和计数不变。
- **补齐固定组分 loader 的性质传递。** 当前 `get_composition_data_loader`
  不接受性质，`CrystalGenerator.get_condition_loader` 的组分分支也不转发性质。
  应在本地模块包装生成的 ChemGraph，显式设置每个晶体的 `dft_band_gap`，并验证
  条件嵌入标志、原始带隙值和实际 scaler 均正确；禁止静默退化成无条件采样。
- 断点续训保留优化器、调度器和随机状态；同样本相同噪声下对比续训结果。

## 怎样判断是否训练成功

验证去噪 loss 仅作为必要的训练诊断，不作为性质条件生成有效的充分证据。
第一期可选约 8 个有多晶型标签支持的组分，每组 4 个配对种子，从相同先验生成；
目标优先取该组分已有多晶型的低/高带隙，第三个目标只在数据支持时添加。
不要让所有组分都盲目追求 2.5 eV，避免把不可实现目标当成模型失败。

对照包括原 CSP、冻结适配器模型的 CFG0、条件 CFG1/CFG2 和打乱目标标签的诊断。
CFG0 的同一输出可用于比较不同目标，不需为每个目标重复生成无条件结构。
对完全相同的目标列表、种子、结构预算和几何接受规则做配对比较。

报告：目标 MAE、目标通过率（容差预先给定）、同组分目标改变时预测带隙的方向
和幅度、结构有效率、MatterSim 力和弛豫收敛率、弛豫前后性质变化及结构多样性。
失败计入总分母，成功条件下的 MAE 与失败率分开报告。
先在有 DFT 标签的干净验证结构上检查 ALIGNN 的误差，再把它用于生成结构评估。
ALIGNN 不参与首版训练，但它仍是预测代理；严格结论需要后续独立验证。

本研究主要目标应是**MatterSim 弛豫后的性质符合程度**。统一相同弛豫参数，
以固定预算评估 `f(R_MatterSim(x))`，同时保留未弛豫值。普通条件去噪训练并未
直接最小化这一复合目标，不能提前保证弛豫后收益。若弛豫抹去条件效应，再考虑
对弛豫后的结构重新标注和第二阶段训练；不能把原结构的 DFT 标签直接无条件
沿用到已经改变的几何。首轮不新增 DFT、SUN 或噪声态性质预测器训练。

## 计划中的代码边界

后续实现拟放在 `experiments/mattergen/csp_bandgap/`，每个子目录附 README：

- `data/`：结构/DFT 带隙输入，输出标签审计、去重与分组清单、训练集 scaler。
- `train/`：基座＋数据清单输入，输出适配器 checkpoint、解析配置和训练台账。
- `sampling/`：精确组分、目标、种子、checkpoint 输入，输出原生 CSP 轨迹和条件审计。
- `evaluation/`：生成物和统一评估配置输入，输出弛豫前后属性与配对统计。

这些模块尚未创建；当前只完成方案与源码核对。
