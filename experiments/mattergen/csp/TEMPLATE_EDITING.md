# 使用已有晶体模板进行 MatterGen 局部编辑

2026-10-30；待实施方案，尚未运行此编辑协议。适用当前周期性晶体问题：已有近似
合适的模板，希望保持元素和整体结构，在附近寻找更好候选。MatterGen 提供候选，
MatterSim 弛豫与目标接受准则决定优化结果。

## 编辑流程

对模板 `xref=(元素A,坐标R,晶胞L)`，保持每个原子的元素身份和原子数：
先转换到模型使用的等价晶胞表示，保持物理结构及原子对应关系不变，记录必要的
整体旋转/晶胞变换，避免把坐标表示变化当成编辑位移。

1. 选低噪声时间 `ts`，按 checkpoint 的原生连续 forward marginal 给 R/L
   加噪得到 `xts`，不对 A 做 MASK 加噪。
2. 从 `xts`、时间 `ts` 开始，仅运行到终点的反向去噪；使用实际返回的终态 mean。
3. 对有效候选做统一 MatterSim 弛豫，检查力收敛、形成能既定要求与模板接近程度。
4. 多个种子产生 N 个候选，按弛豫后的真正目标选 best of N。把可行的直接弛豫
   基线保留在候选集中；没有改善时返回基线。这个保底只针对所采用的代理指标。

若需多轮优化，每轮 N 个候选共同从当前最优模板出发，批次结束后才更新模板，
只接受可行且代理目标更好的候选。累计距离约束仍相对于最初的 xref，而非仅约束
相邻两轮；否则多轮小改动仍可能造成较大漂移。无改善时保留当前结果并停止或
调整搜索尺度，不能把每次去噪都解释为保证改进的优化步。

这借鉴 [SDEdit](https://arxiv.org/abs/2108.01073) 的加噪再去噪思想；该论文研究图像，
并非已验证本晶体任务的效果。小噪声通常更保留模板，大噪声允许更大变化，但
保真与改善都须测量，不能从噪声时间直接推断。

## 先用哪些现有权重

- 现有 GSS CSP 可作固定组分、无带隙条件的局部编辑基线；它学习结构先验，
  不具备已训练的带隙定向控制。可借候选筛选寻找性质改善，不能宣称 score 本身
  是性质梯度或能量最小化力。
- 现有 `dft_band_gap` 联合生成权重值得直接测试低噪声模板编辑：完整元素输入
  在后段更接近模型原有的低噪声训练情形。它不等于从纯噪声固定组分的 CSP，
  也不需要先宣称已得到一个性质 CSP checkpoint。元素保持、适用组分及局部性
  均为待验证条件；每步断言元素和计数完全不变，不能静默接受元素突变。
- 首个性质实验优先对同一个带隙 checkpoint 比较 CFG0 与 CFG2，避免把不同基座
  的差异归因于带隙条件。若该编辑方式有效，再决定是否值得训练专用条件 CSP。

## 原生采样器需要怎样接入

公开 `sample(conditioning_data, mask)` 会先调用 `_sample_prior`。仅把模板坐标
装进 conditioning_data，不会自动以模板作为反向去噪起点。必须增加明确的
warm-start 输入路径，绕过 prior 重置，沿用已核对的原生更新算子。

默认原生时间网格为 `t[k]=1-0.001*k`，k=0..999，终点0.001。首版建议保留末尾
K=50/100/200轮作三个编辑尺度，对应 `ts=0.05/0.10/0.20`。模板应先匹配该 ts
的几何边际分布，再依次用原网格 ts..0.001；连续 dt 保持-0.001。K 表示去噪轮，
每轮原生含一次 corrector 和一次 predictor，绝非从最高噪声跑更粗的 K 轮。

`max_t` 只影响反向网格，不能单独替代 warm-start 初始化。联合模型的离散元素
diffusion 绑定1000训练步，构造器会检查这一 N；不得简单将 sampler.N 改成 K。
应保留原1000步定义及离散时间映射，在本地封装显式的后缀循环。即使元素固定，
也要保留这个时间语义并核对逐步状态。固定组分 CSP 没有离散 corruption，但
比较时仍须保持同样原生后缀定义，避免将网格变化误当编辑效果。

不同字段的原生加噪不同：坐标是 wrapped VE，晶胞是 lattice VP，不能给两者
随意添加同一个 Cartesian 高斯扰动。记录实际周期性 Cartesian RMS 位移与晶格
应变，按测量结果调整 ts；ts不是Å。保留几何有效性和有限值检查。

首版可让坐标/晶胞联合按原生边际少量变化，并限制最终晶格应变。若需严格固定
晶胞或一部分原子，可以增加 inpainting/约束消融，但应作为受约束采样变体验证，
不默认它等价于模型已经学好的条件分布。每步强投影/裁剪也会改变采样过程。

## 接受目标与公平对照

如果目的仅为减少力、改善几何，直接 MatterSim 弛豫是必须的基线。如果目的是
提高带隙符合程度，则按 `abs(ALIGNN(R_MatterSim(x))-target_gap)` 选择，不能只看
未弛豫带隙。候选须满足既定稳定口径与模板距离/应变约束；不额外声称 DFT 稳定性。

对同一父模板和相同连续噪声，比较：

| 分支 | 过程 |
|---|---|
| 直接弛豫 | 模板 -> MatterSim |
| 仅噪声 | 原生匹配加噪 -> MatterSim |
| 无性质编辑 | 同一加噪状态 -> 带隙模型 CFG0 后段去噪 -> MatterSim |
| 带隙条件编辑 | 同一加噪状态 -> 同一模型 CFG2 后段去噪 -> MatterSim |

拟议第一轮可用4个支持范围内父结构、每个尺度4个配对种子、三个K尺度：每个
随机分支48候选，直接弛豫4个基线。尚未提交这些作业。分别报告每个K下best-of-4；
合并best-of-12只能作为额外明确标注的预算，不能隐去更大的候选数。

报告性质 MAE/通过率、有效候选率、弛豫收敛率、每父结构改善、物理/模型调用
及墙钟时间。失败保留在分母。几何距离须处理周期边界、整体平移/旋转和同元素匹配；
区分晶格应变与原子内部位移，检查弛豫后是否真正不同于直接弛豫结果。
如果所有小噪声候选回到同一极小值，说明该搜索尺度没有产生收益；再尝试更大的
编辑范围，不能把几何数值差异当作新结构。

原始模板、直接弛豫、编辑未弛豫和编辑已弛豫结果全部保留。score 不保证逐步
降低真实能量或目标带隙误差；带隙条件也只提供偏置，最终改善须由实验确认。

## 实现前的验收计划

本地实现拟扩展独立 warm-start sampler 与评估模块，并附 README：输入模板、
checkpoint、ts/K、种子与目标，输出轨迹、条件/元素审计与统一弛豫统计。
测试覆盖：prior确实被绕过、初始化等于给定加噪状态、第一/最后时间及dt、
native原生K轮等价/调用数、离散1000步映射、元素逐步不变、CFG条件实际启用、
RNG配对与旁观记录中性、真实terminalmean、位移/应变和失败分母、best-of-N预算。
模板不变但坐标被重新随机化必须作为测试失败。所有远程模型计算经Slurm；
本方案不自动启动训练、DFT、SUN或任何采样实验。
